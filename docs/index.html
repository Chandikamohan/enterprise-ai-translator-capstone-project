Enterprise AI Translator

Static homepage for the Streamlit AI translation project. This page is optimized for GitHub Pages hosting.

About

This repository contains a Streamlit app that uses Google Gemini and gTTS to translate text and documents into 12 target languages and generate downloadable audio.

Run Locally

  1. Create a Python virtual environment and activate it.
  2. Install dependencies: pip install -r requirements.txt
  3. Copy .env.example and set GEMINI_API_KEY.
  4. Run the app: streamlit run app.py

GitHub Pages Hosting

The static site is served from the docs/ folder. When Pages is enabled on the repository, this landing page will be published automatically.

Note: GitHub Pages hosts static content only; the dynamic Streamlit app itself must run on a separate server or hosted service.

Deployment Options

  • Docker / Docker Compose
  • Streamlit Cloud
  • Render, Railway, or any Python-compatible host
